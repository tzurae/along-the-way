# Issue tracker

GitHub Issues is the source of truth for product and engineering work in this
repository.

- Parent design/specification: GitHub Issue #1.
- First implementation ticket and current scope: GitHub Issue #2 (`[01]`).
- Branches use `feat/issue-<number>-<short-name>`.
- Commits and pull requests reference the implementation issue number.
- A ticket is complete only when its acceptance criteria have fresh verification
  evidence. External deployment prerequisites remain explicit instead of being
  reported as completed.
